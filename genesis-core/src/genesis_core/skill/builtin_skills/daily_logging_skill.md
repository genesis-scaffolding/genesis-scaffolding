# Daily Logging Skill

This skill is triggered when user wants to "log", "add to log", or "record" that something happened.

When requested, create a new log line in the daily journal entry for today. Create the journal entry and a section for the log if they do not exist. Each log line should have a time stamp and the content.

Example: "16:48 - Finished a preliminary version of the long-horizon plan system"

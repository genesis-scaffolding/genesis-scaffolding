description: Run an end-of-day reflection session with the user. Trigger when user asks to reflect on the day, wrap up the day, or says "let's reflect" or "let's wrap up". This is intended for late afternoon or evening.

## Daily Reflection Session

### Step 0 — Time Check

Check the current time. If it is clearly morning or midday, gently flag this to the user ("This is usually an evening activity — are you sure you want to do it now?"). If the time cannot be determined, proceed regardless.

### Step 1 — Gather Context

Search and read the following:

- Today's daily journal entry (if it does not exist, create a blank one using the template)
- This week's weekly journal entry (if it does not exist, skip)
- Tasks assigned today or earlier (overdue)

Also read the current daily journal to see what logs have been recorded.

### Step 2 — Determine What Was Done Today

Look at:

- Are the daily goals from today's journal marked as complete in the task system?
- Are there log entries in today's journal that show what was accomplished?
- If there are no logs and no completed tasks, tell the user: "I don't have a record of your progress today. What did you achieve?" Then wait for their answer.

Present the findings conversationally: "From our records, it seems today we [description of what was done]. Does that sound right? Is there anything missing?"

If the user says something is missing, ask them to share it, then add it to the daily journal's Logs section.

### Step 3 — Reflection Interview

Once the daily log is accurate, conduct a short reflection interview.

Ask **one question at a time**. Do not batch them. Choose from the list below or write new ones that feel relevant to the day's events:

- What decision did you make today that you're still not sure about?
- If [something the user did today] compounds — meaning it makes future sessions better — does that change how you feel about the trade-off?
- What story are you telling yourself right now that might not be entirely true?
- When you catch yourself reaching for that story, what's actually underneath it?
- Did you treat yourself the way you treat someone you respect?
- What did you learn today?
- What is your most proud result today?
- What's one thing you would do differently if you had today to do over?
- Was there an emotion that showed up today that you didn't expect or didn't want?

After three questions, ask: "Is there anything else on your mind? Feel free to write it down here in free form."

### Step 4 — Write the Reflection to Journal

Write the reflection into today's journal entry under the ## Reflection section.

Format each question-answer pair as a standalone paragraph. Use the exact words the user said — do not paraphrase.

Structure:

```
## Reflection

[Question 1]
[User's exact answer, in their words]

[Question 2]
[User's exact answer, in their words]

[Question 3]
[User's exact answer, in their words]

Other reflection
[Any free-form text the user wrote]
```

The "Other reflection" paragraph is for anything the user wants to add that does not fit under a specific question.

### Step 5 — Done

No further action required. The reflection is saved.

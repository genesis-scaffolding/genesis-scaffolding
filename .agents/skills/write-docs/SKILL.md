# Write Documentation

Write or update documentation for this project.

## Workflow

### Step 1: Read the Guide

Before doing anything else, load `docs/documentation.md` to understand the documentation setup, conventions, and requirements.

### Step 2: Clarify Requirements

Ask the developer what needs to be documented:

- What is the subject? (code change, new feature, new module, etc.)
- Where should the documentation live? (existing file or new file)
- Any specific audience or format requirements?

### Step 3: Present Documentation Plan

Based on the requirements and your understanding of the docs, draft a plan:

- What files to create or update
- What content to include in each file

Present this to the developer for review.

### Step 4: Iterate Until Approved

Refine the plan based on developer feedback. Repeat until the developer approves.

### Step 5: Write the Documentation

Only after approval, write or update the documentation files following the patterns in the guide.

## Reference

For documentation conventions, file structure, and writing guidelines, read `docs/documentation.md`.
